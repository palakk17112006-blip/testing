# testing# 📚 Resources Dashboard

A modern and responsive **Resources Management Dashboard** built using **HTML, Bootstrap 5, and Font Awesome**. This dashboard provides an organized way to display resources, documents, images, Excel files, and other downloadable assets through an attractive user interface.

## 🚀 Features

- Clean and modern UI design
- Fully responsive layout using Bootstrap 5
- Dashboard statistics cards
- Resource search functionality
- File type filtering options
- Resource category tabs
- Downloadable resource cards
- Font Awesome icons integration
- Professional card-based design

## 🛠️ Technologies Used

- HTML5
- Bootstrap 5.3
- Font Awesome 6
- CSS Utility Classes

## 📋 Dashboard Sections

### Navigation Bar
- Resource title and breadcrumb navigation
- Search bar for resources
- File type filter dropdown

### Statistics Overview
- Total Resources
- Documents Count
- Images Count
- Other Files Count

### Resource Categories
- All Resources
- Documents
- Images
- Excel Files
- CDR Files
- Other Files

### Resource Cards
Each resource card contains:
- Preview image
- Resource title
- File type information
- File size
- Download button
